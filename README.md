# Codicent M3 MCP

Public product and installation site for the Codicent M3 MCP Docker image.

**Website:** https://m3.codicent.ai/

## About this repository

This public repository contains only the static marketing and product-documentation
site. The runnable image is published as `izaxon/mcp-m3` on Docker Hub. Server
source, customer configuration, endpoints and credentials remain private and are
not published here.

The canonical site source lives in the private `izaxon/codicent-core` repository
and is synced here automatically. Direct changes to this repository will be
overwritten by the next sync.

For verified setup and workflow support, contact [johan@codicent.com](mailto:johan@codicent.com).
